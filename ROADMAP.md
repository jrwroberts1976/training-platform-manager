# Engineering Learning Platform Roadmap

## Vision

Build a self-hosted, Git-driven engineering learning platform that automatically discovers, validates, publishes and maintains technical training from multiple repositories.

## v1.0
- Independent course repositories
- Automatic synchronisation
- Validation
- Navigation generation
- Homepage generation
- Statistics
- Learning paths
- Docker deployment

## v1.1
- doctor command
- status command
- Repository health
- Broken link detection
- Deployment reports

## v1.2
- Featured courses
- Technology coverage
- Related courses
- Improved search

## v1.3
- Plugin architecture
- Theme support
- Release automation

## v2.0
- User accounts
- Progress tracking
- Notes
- Quizzes
- Certificates
- REST API
